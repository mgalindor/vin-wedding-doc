Do's & Don'ts

Core guardrails for maintaining the design system's intent and quality.

✓ Do
  • Use display-lg / headline-md (Playfair Display) for the couple's names and wedding date on all guest-facing surfaces.
  • Use primary Gold exclusively for interactive elements in the dashboard.
  • Provide 80px+ vertical breathing room between invitation modules on desktop.
  • Reserve rounded-full exclusively for status badges and avatar chips.
  • Write all UI labels in label-caps — Inter 12px / 600 / tracked / uppercase.
  • Use the data-tabular token in all table cells with numeric or date content.
  • Support both English and Spanish in every UI string from day one.
✗ Don't
  • Use primary Gold on decorative shapes, dividers, or illustration fills.
  • Render Playfair Display below 20px — switch to Inter at small sizes.
  • Use full-bleed images on the planner dashboard — they belong to invitation surfaces only.
  • Apply the ambient card shadow to inline table rows, form fields, or nav items.
  • Use more than two type sizes on a single card or panel.
  • Ship a UI string without its Spanish equivalent — untranslated strings are bugs.
  • Use red (error) for any RSVP status other than Declined / error states.
